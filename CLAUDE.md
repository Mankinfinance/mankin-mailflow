## Release notes

Every set of release notes (the Notion "Mailflow - Release Log" page and any release email) carries a **version number and a date**, e.g. "Mailflow 1.2 - 8 November 2026", in the title or subject and at the top. Versions so far: 1.0 (23 September 2026, rows 1-21), 1.1 (23 October 2026, rows 22-35), 1.2 (8 November 2026, rows 36-43). Each new release round takes the next minor version, gets a row in the Versions table at the top of the Release Log, and the shipped rows say which version they belong to.

Release emails go out as an Outlook draft (`.eml` with `X-Unsent: 1`) addressed to Mankin Finance All <MankinFinanceAll@mankinfinance.com>. Write them as a single `text/html` part, 7-bit ASCII (use HTML entities for curly quotes, dashes and arrows), so no quoted-printable `=` codes appear when opened.
